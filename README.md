# 🚀 Exercícios de Consumo de APIs

Projeto desenvolvido durante as aulas de desenvolvimento web do **SENAI**, com o objetivo de praticar o consumo de APIs utilizando JavaScript, `fetch()` e funções assíncronas (`async/await`).

O projeto reúne diferentes exercícios de consultas a APIs externas e arquivos JSON locais, trabalhando com requisições, conversão de dados e tratamento de erros.

## 📚 Conteúdos praticados

- Consumo de APIs utilizando `fetch()`.
- Utilização de `async/await` para requisições assíncronas.
- Conversão de respostas utilizando `.json()`.
- Manipulação de dados retornados pelas APIs.
- Tratamento de erros com `resposta.ok`.
- Verificação de informações retornadas no JSON.
- Manipulação do DOM para exibição dos resultados.
- Utilização de eventos com `addEventListener()`.

## 🔎 Exercícios desenvolvidos

| Exercício | Descrição |
|---|---|
| Consulta de produto | Busca informações de um produto pela API DummyJSON. |
| Produto por ID | Consulta produtos utilizando um ID específico. |
| Consulta de CEP | Busca endereço utilizando a API ViaCEP. |
| Categoria de produto | Consulta a categoria de um produto. |
| Usuário por ID | Busca informações de usuários. |
| Lista de produtos | Retorna uma lista com 10 produtos da Fake Store API. |
| Post por ID | Consulta publicações utilizando um ID. |
| Tarefa por ID | Consulta tarefas e seus respectivos status. |
| Ordens da fábrica SENAI | Consome dados de um arquivo JSON local. |
| Desafio secreto | Exercício bônus utilizando um arquivo JSON local. |

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## 🌐 APIs utilizadas

- [DummyJSON](https://dummyjson.com/) – Produtos, usuários, publicações e tarefas.
- [ViaCEP](https://viacep.com.br/) – Consulta de endereços por CEP.
- [Fake Store API](https://fakestoreapi.com/) – Listagem de produtos.

## ▶️ Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/gustavoferraritech-spec/lista_exercicios_api.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd lista_exercicios_api
   ```

3. Abra o projeto no VS Code.

4. Execute a página utilizando a extensão **Live Server**.
